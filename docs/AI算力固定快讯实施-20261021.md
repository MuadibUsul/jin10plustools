# AI算力CPI 与 AI景气度指标固定快讯实施（2026-10-21）

## 已上线栏目

两个固定快讯栏目已接入现有固定快讯生产链：

- `token_cost`：AI算力CPI（Token支出价格，美元/百万Token）
- `gpu_rental`：AI景气度指标（A100/H100/B200 NeoCloud租赁价格，美元/GPU/小时）

生产首页的栏目卡、任务、版本、确认、图片下载、固定注释、Skill 库和数据库导出均按现有机制工作。

**两个栏目默认不进入自动排期**：`AUTO_CATEGORIES` 仍为原七个栏目；新栏目由编辑手动生成，直到数据源和时效阈值另行验证。手动生成不受上午生产窗口限制，并自动采用数据库中最新的可用数据：Token 取最新非空价格行，GPU 取最新完整三卡行；若数据日早于目标数据日，稿件会标注实际数据日并在警告中说明，不需要编辑选择历史日期。手动生成也会绕过同日旧缓存，先刷新来源再出稿。

## 计算与文字

- Token：周变化 = 当日价格 ÷ 七个自然日前价格 − 1；缺失基准时不报告周变化。历史图保留长期趋势和最近30日局部趋势。
- GPU：只使用同日 A100/H100/B200 三卡完整行；周变化按七个自然日对齐；历史峰值按各卡已导入非空序列计算，等于高点写“并列”，严格超过才写“新高”；不把三卡样本扩写成全部芯片。
- 两个适配器会写入 `ai-compute-source.json` 快照，进入来源归档和过程核对；来源快照的 `data_date` 记录实际数据日，而不是生产日。
- 图表使用 CJK 系统字体回退、ISO 日期刻度、原 PLUS 水印；交付图片仍受 266,000 字节限制。
- Skill 库新增两个文字 Skill 卡片（`jin10-plus-token-cost-text`、`jin10-plus-gpu-rental-text`），使用工作簿附件中的真实参考文段/校正说明；生产 Skill 阶段读取对应 `SKILL.md` 和历史样本润色，数字守卫保留。
- 固定三条说明使用 `delivery.FIXED_NOTES` 的样本原文，画在图表页脚；正文只保留动态事实。团队成员仍可在设置中修改，重新制图后页脚跟随该注释。

## 边界

- 官方 Silicon Data API 仍需要授权；当前数据来自归档工作簿，不能称为实时自动取数。
- 新栏目默认不自动排期；编辑直接手动生成即可自动取最新已导入数据，但数据源仍不是可验证的日更 API。
- 2026-10-21 上线时每类只有一条参考文段，未伪造 20 条历史。2026-10-26 起，Skill 生产改为使用 ethan 提供的 18 则 Token 风格样本和 11 则 GPU 风格样本；样本不是当期事实，规则稿仍由事实包按风格模板生成。
- 生产正文/固定说明/图表数字需继续人工核对；AI 不得改数字、单位、日期、比较窗口或极值结论。
