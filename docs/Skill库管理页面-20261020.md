# 设置 → Skill 库管理页面（2026-10-20）

## 已上线

正式站设置页左侧新增 **Skill 库**（位于“AI接口设置”和“小电视直播”之间）：[https://plus.tlines.tech/settings/#skills](https://plus.tlines.tech/settings/#skills)。

页面列出五项固定快讯文字 Skill：

- 成交额 `news.fixed-volume@0.1.0`
- 换手率 `news.fixed-turnover@0.1.0`
- 估值 `news.fixed-valuation@0.1.0`
- 流动性 `news.fixed-liquidity@0.1.0`
- 原油ETF `news.fixed-oil-etf@0.1.0`

每项展示内置规范、团队版本、启用状态、摘要、历史样本数量与修改记录。

## 可以做什么

- 查看当前生效的 Skill 规范（`SKILL.md`）。
- 管理员编辑团队规范并保存；留空可恢复内置规范。
- 管理员启用/停用某项 Skill。
- 查看每次修改的版本、时间、操作人和启用状态。
- 所有登录成员可查看；编辑仅管理员可用。
- 团队隔离：其他团队看不到本团队的覆盖内容。

修改只影响 `/briefs/` 中“Skill 文案预览”的 AI 润色提示，**不会**改变自动生成规则、数字、图片、已生成稿件或发布流程。停用后预览会直接显示完整生产规则稿。

## 技术实现

- 存储：`Team.settings["skills"][category]`，包含 `enabled`、`instructions`、`revision`、`updated_at`、`updated_by`、`updated_by_name` 和最多 20 条历史；没有新增数据库表/迁移。
- API：
  - `GET /api/settings/skills`：所有登录成员，团队隔离。
  - `PUT /api/settings/skills/{category}`：仅管理员；请求 `revision`、`enabled`、`instructions`，版本冲突返回 409。
- AI 预览：`app/briefs/skill_ai.py` 优先读取团队规范；未覆盖时读取生产镜像 `/srv/skills` 中的内置 `SKILL.md`。数字守卫、导流/投资建议拦截和失败回退保持不变。
- UI：`app/web/settings.html`、`settings.js`、`skill-library.css`。
- 镜像：`plus-api:skill-library-20261020`；生产迁移仍为 `0011`。
- 页面不执行 Skill 规范中的任何代码；规范只作为模型提示文本，输出仍经过数字校验。

## 边界

- 当前只管理五项固定快讯文字 Skill；不支持上传任意 Python Skill 或修改运行时 manifest 代码。
- Skill 库的团队覆盖保存在设置 JSON，不进入数据库导出面板；如需纳入导出，应另立数据模型。
- 规范编辑器不替代取数/事实核查；AI 仍只能改写已校验规则稿，不能补造缺失事实。
- Plus新鲜事、Plus注解辅助页面和 `news_*` 持久化工作台仍未上线。
