# AI 算力图表核对样本

`token-cpi-after.png` 和 `gpu-rental-after.png` 由仓库中的两份原始 Excel 工作簿实际数据自动生成，不使用合成走势。图表测试逐点核对程序曲线与工作簿数值。

- Token 原 Excel 图引用 `Sheet1!A3:A311`，即最近 309 个非空观测；基准工作簿的可见日期为 2025-12-06 至 2026-10-14。
- GPU 原 Excel 图引用 `Sheet2!A3:A371`，其中两行为空，实际为最近 367 个有价格的日期；基准工作簿的可见日期为 2025-10-07 至 2026-10-15。
- 后续新数据继续采用同样的滚动观测数。缺失日期不生成观测点；某张卡当日缺价时，该卡曲线在该日断开，不补零、不沿用前值。B200 青绿、H100 淡紫、A100 金黄，并保留柔和投影。
- 日期标签改为少量水平标记，减少横轴占用；三条固定注释位于图例下方。用户下载时，由统一交付管道追加原版 PLUS 水印并执行 266 KB 限额。

`*-before.png` 仅保留旧布局对照；不可作为实际行情样本。
