## AI景气度指标原始参考

【AI景气度指标】高端GPU租赁价创半年新高，市场呈现代际分化

截至10月15日，英伟达B200租赁价格升至6.01美元/GPU每小时，较一周前上涨2.21%，创3月下旬以来阶段性高位，距离历史数据中的6.11美元高点仅约1.64%。同期，H100租赁价格报2.81美元，微涨0.36%；A100报1.52美元，下跌0.65%。数据显示，新一代GPU租赁价格持续走强，而上一代产品表现相对疲弱，反映AI算力租赁市场出现代际价格分化。

--------

1、GPU租赁价格指数主要统计每天云服务商、数据中心和私人租赁市场中英伟达A100、H100、B200等GPU的实际租赁报价。

2、A100、H100、B200是英伟达从老到新三代芯片产品（GPU），通常代际越新的GPU性能越好、越能适应大规模复杂大模型，租赁价格也往往越高。

3、由于GPU价格太高、更新太快等原因，不少企业选择向云服务商、数据中心等租赁芯片，以节省资金投入。相关指数上涨通常意味着GPU更紧缺、需求更旺；下降则说明供应增加或需求降温。通过观察价格趋势，以及比较新旧GPU之间的价格差，投资者可了解当前AI算力的景气度。
