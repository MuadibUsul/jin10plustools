## 当前边界

- 附件是需求参考，不代表仓库代码已具备其中描述的能力。所有“已完成”项需有文件或命令结果支持。
- 2026-10-20 已在正式站 `/briefs/` 上线**固定快讯五项 Skill 只读文案预览**（镜像 `plus-api:skill-preview-20261020`），详见[发布记录](../固定快讯Skill文案预览上线-20261020.md)；它不自动替换生产稿、不发布，也不代表持久化/通用 API 已上线。
- 持久化 `news_*` 表、事件/草稿/工作流 API 仍只在隔离环境验证，未部署生产；生产迁移仍为 `0011`，`NEWS_SKILL_OS_ENABLED` 保持关闭。
- 五类文字 Skill 和 100 条历史样本经用户明确指定为本系统关键资产；采用独立提交，以便审阅来源、规则与后续适配。
- 新的 `news_*` API 可以持久化事件/证据/草稿/运行，但 Plus新鲜事、Plus注解辅助页面尚未接入，仍为占位入口；真实新闻输入、在线模型和自动核查未实现。
- 研究流程仍只运行仓库内三个样例或调用方提交的结构化事件；五类文字预览入口不持久化、不独立核查来源、不调用付费模型、不发布。五类文字资产已适配 Manifest，但尚未接入自动生成任务。
- 无自动发布、无 CMS 调用、无默认常驻 worker；审核通过只表示可人工取稿。
