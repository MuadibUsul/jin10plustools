# 使用者反馈（2026-10-17）

## 需求

- 在设置左侧“数据库”下方新增“反馈”面板，主要给使用者提交新的改进意见。
- 必填：标题、内容、提交人姓名；可选上传一张示意图。姓名用于后续对接。
- 反馈入库并进入数据库导出，供按时间范围核对与跟进。

## 交互

- 左侧导航：团队设置 / 数据库（仅管理员）/ 反馈（所有登录成员）。编辑、只读账号都能提交；非管理员看不到数据库入口，但反馈入口正常。
- 表单：标题（≤200字）、内容（≤5000字）、提交人姓名（默认填入当前账号名，可修改）、示意图（PNG / JPEG / WebP，≤5MB）。提交成功后清空标题、内容与文件，保留姓名，并刷新下方“最近的反馈”。
- 最近反馈列表（每团队最近 50 条）：标题、提交人姓名、账号（与姓名不同时显示）、提交时间、“我提交的”标记；有示意图时提供“查看示意图”按钮，点击后才读取并显示图片。

## 数据与接口

- 新表 `feedback`（迁移 `0011_feedback`）：`team_id`、`user_id`（账号）、`name`（填写的姓名）、`title`、`content`、图片元数据（相对路径、类型、字节数、SHA-256）、`created_at`；按团队隔离。
- 图片保存在数据卷 `<storage>/<team_id>/feedback/<id>.<ext>`，表中只登记元数据与校验值。
- 接口：
  - `GET /api/feedback`：本团队最近 50 条（新→旧），带 `mine` 与图片标记；
  - `POST /api/feedback`：multipart 表单，任何登录成员可提交；标题/内容/姓名非空并限长，图片按魔数校验类型、5MB 上限（`max_feedback_bytes`）；
  - `GET /api/feedback/{id}/image`：团队内可读，路径校验后返回原图，未登录 401、跨团队 404。
- 数据库导出新增“使用者反馈”数据集（管理员，按提交时间筛选）：标题、内容、姓名、提交账号、示意图类型/字节数/SHA-256、是否有示意图、提交时间；图片二进制不导出。

## 验证

- 后端 `tests/test_feedback.py` 5 项：只读账号可提交并读回、列表排序与归属标记、跨团队不可见（列表为空、图片 404）、字段校验（空标题/内容/姓名 422、非图片魔数 415、超限 413）、未登录 401、反馈可在导出中查到且不含图片二进制。
- 后端全套 155 项通过（4 项因无独立 PostgreSQL 测试库跳过），前端全套 68 项通过，typecheck 与 lint 通过。
- 端到端（`out/live-harness/verify_export_e2e.py`，临时 SQLite + 真实服务 + 浏览器）：编辑账号打开反馈面板、姓名预填“编辑甲”、上传 120×80 PNG 提交成功、列表出现反馈并可查看示意图（naturalWidth=120）；管理员在数据库面板选择“使用者反馈”预览到 1 行。截图 `out/feedback-20261017.png`。
