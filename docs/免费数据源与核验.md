## 巴菲特指数与ERP

巴菲特分子为全A，不是沪深300市值。东方财富全公司总股本按A股价计价的候选，与乐咕已保存历史存在差异；最新两日替换时写明来源，原始历史不声称已按候选源全量回算。原始历史存在重复分类日期，绘图按原记录保留，不自动改日。

ERP公式不变：`1 / PE-TTM市值加权 - 十年期国债收益率数字 / 100`。免费PE来源及中债曲线与旧模板定义的差异通过warnings和核验信息展示，可先部署测试，再按审阅意见改。标准化完整历史随成功运行更新，不每天从固定旧种子重新开始。

国家统计局GDP是年度分母，配置在`app/briefs/seed/gdp.json`。新增年度时应查国家统计局正式全年值、记载出处及修订版本；缺年度值时暂停而不是默默使用前一年分母。
