# 固定快讯五项文字 Skill 文案预览上线（2026-10-20）

> 后续变更：用户已决定固定快讯内容产出必须自动走 Skill，并移除页面上的“采用AI文字 / Skill 文案预览 / 补跑AI”按钮。当前生产行为见[固定快讯 Skill 自动产出](固定快讯Skill自动产出上线-20261020.md)；本页保留为手动预览阶段的历史记录。

## 已上线内容

正式站 `https://plus.tlines.tech/briefs/` 的固定快讯编辑区新增 **Skill 文案预览**。适用于五个栏目：

- 成交额（`volume`）
- 换手率（`turnover`）
- 估值（`valuation`）
- 流动性（`liquidity`）
- 原油ETF（`oil_etf`）

打开任一固定快讯版本后，点击“Skill 文案预览”，系统以该版本**已校验的生产规则稿**为事实源，结合对应 `SKILL.md` 规范、历史文段风格和团队配置的 AI 接口，返回润色后的标题与正文。编辑可以复制，或点“采用到编辑区”，再按原有流程保存、确认和取稿。

本次是**辅助预览**，不是自动替换生产生成稿，也不会自动发布。原有取数、制图、AI 文案、人工确认和图片下载流程不变。

## 两层生成与安全回退

1. **生产规则稿**：`title` 和 `dynamic_body` 来自所选 `BriefVersion`，已经过原有取数、校验和人工流程；是唯一事实来源。
2. **AI 润色层**：读取团队设置中选择的 AI 接口（DeepSeek / chat2api / OpenAI），把 `SKILL.md` 作为编辑规范、历史文段作为风格参考，只改表达、句序和衔接。
3. **数字守卫**：AI 回答必须与规则稿的数字集合完全一致；新增、删除或改动任何数字都会拒绝。新增“点击查看、关注、布局、投资建议、链接”等原文没有的内容也会拒绝。
4. **失败回退**：AI 未配置、超时、输出不合法或数字不一致时，直接返回完整生产规则稿并给出提示，不会显示空稿或残缺稿。
5. **固定注释**：仍来自所选版本的团队配置，不交给 AI；AI 不得把注释并入正文。

## 已知边界

- AI 润色基于已经完成事实校验的生产规则稿，**不会补造规则稿没有的前值、连续天数或政策利率**；要增加事实，必须先回到取数/适配器层。
- 当前团队 chat2api 设置请求 `gpt-5.6-sol`，节点实际使用 `gpt-4o-mini`；响应会带 warning。若需要更强润色，应在设置中换用节点支持的模型或配置 OpenAI。
- 数字守卫采用“数字集合必须完全一致”的保守策略；AI 若改写日期格式导致数字集合差异，会回退生产规则稿，而不是冒险采用。
- 采用预览只修改编辑区标题和正文，不修改固定注释；编辑仍需保存并确认。
- 真正的自动生成接入、Plus新鲜事/注解审核页面和 `news_*` 持久化链路仍属于后续阶段，本次没有部署。
