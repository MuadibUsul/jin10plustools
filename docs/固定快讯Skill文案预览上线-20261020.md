# 固定快讯五项文字 Skill 文案预览上线（2026-10-20）

## 已上线内容

正式站 `https://plus.tlines.tech/briefs/` 的固定快讯编辑区新增 **Skill 文案预览**。适用于五个栏目：

- 成交额（`volume`）
- 换手率（`turnover`）
- 估值（`valuation`）
- 流动性（`liquidity`）
- 原油ETF（`oil_etf`）

打开任一固定快讯版本后，点击“Skill 文案预览”，可以看到由该版本已入库事实生成的标题、动态正文和固定注释；编辑可选择“采用到编辑区”，再按原有流程保存、确认和取稿。

本次是**辅助预览**，不是自动替换生产生成稿，也不会自动发布。原有取数、制图、AI 文案、人工确认和图片下载流程不变。

## 技术范围

- API：`GET /api/briefs/issues/{id}/skill-preview?version=N`
  - 仅团队内可见；只读账号只能预览已确认版本。
  - 从所选 `BriefVersion.payload` 映射五项 Skill 所需的已验证事实，调用 `news.fixed-{volume,turnover,valuation,liquidity,oil-etf}@0.1.0`。
  - 返回 `publication_allowed=false`、`human_approval_required=true`。
  - 证据 ID 形如 `brief:{version_id}:{number}:{fact}`，指向产生该预览的稿件版本；不是新的持久化证据表。
- UI：`app/web/briefs.html`、`app/web/briefs.js` 的原生 dialog；复制、采用和提示复用现有工作台。
- 镜像：`plus-api:skill-preview-20261020`。
- 生产迁移仍为 **0011**；本次没有创建 `news_*` 表，也没有开启 `NEWS_SKILL_OS_ENABLED`。Plus新鲜事/Plus注解辅助页面和通用 News Skill OS API 仍未上线。

## 已知边界

- 成交额稿件事实未保存前一有效交易日成交额，因此 Skill 预览只显示当日成交额和20日均线，不显示前值变动；原生产正文仍保留完整前值计算。
- 流动性稿件事实未保存前一日 DR007 和政策利率，因此预览只显示当日加权利率；原生产正文仍保留来源跟踪。
- 预览使用当前版本快照中的事实和团队注释，不重新抓取行情；数据日期、数值仍以原版本为准。
- 采用预览只修改编辑区标题和正文，不修改固定注释；编辑仍需保存并确认。
- 真正的自动生成接入、Plus新鲜事/注解审核页面和 `news_*` 持久化链路仍属于后续阶段，本次没有部署。
