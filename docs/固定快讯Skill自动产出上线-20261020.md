# 固定快讯 Skill 自动产出上线（2026-10-20）

## 最终交互

用户已确定：固定快讯的内容产出**必须走 Skill**，界面上不再保留“采用AI文字”“Skill 文案预览”“补跑AI”这些手动入口。

- `/briefs/` 只做查看、编辑、保存、确认和取稿；不再显示文案 AI 按钮。
- 五个固定快讯栏目（成交额、换手率、估值、流动性、原油ETF）在生成任务中自动执行 Skill 文案阶段。
- AI 未配置、额度耗尽、超时或输出不合法时，自动回退到完整的固定组合规则稿；任务仍然成功，数字、图片和固定注释不受影响。
- 设置 → Skill 库继续用于管理员维护团队 Skill 规范、启用/停用和查看修改记录；这些修改只影响后续 Skill 产出。
- 设置 → AI接口设置选择 Skill 使用的 AI 引擎与模型。

## 生产流程

1. **规则与数据阶段**：原有取数、计算、制图、来源快照和规则稿生成不变；规则稿是唯一数字来源。
2. **Skill 文案阶段**：`app/briefs/skill_production.py` 在 runner 返回后调用 `skill_ai.polish`：
   - 读取团队 Skill 库覆盖或内置 `SKILL.md`；
   - 读取历史文段作为风格参考；
   - 通过团队选择的 AI 接口润色标题/正文；
   - 数字集合必须与规则稿完全一致；新增/删除/改数、导流语或投资建议会被拒绝；
   - 成功则用 Skill 文案替换标题/正文；失败则保留规则稿并写入回退提示。
3. **归档与版本**：来源快照、图片、固定注释、版本历史照旧保存；没有自动发布。

旧 runner 的“生成时 AI 候选”在 worker 中通过 `SKILL_PRODUCTION=1` 跳过，不再额外消耗 AI 额度。旧 `skill-preview` 后端接口仍存在但不被页面调用；前端按钮和弹窗已删除。

## 边界

- 仅五项有固定快讯文字 Skill 的栏目自动使用 Skill；美股晴雨表/美股结构仍按各自规则生成。
- Skill 规范是提示文本，不执行代码；不能借 Skill 库改变取数、数字或图片。
- AI 额度耗尽时不会重试到失败，也不会生成空稿；直接使用规则稿并提示。
- 已有历史版本不回写；新版本才使用 Skill 自动产出。
- Plus新鲜事、Plus注解辅助和 `news_*` 持久化工作台仍未上线。
