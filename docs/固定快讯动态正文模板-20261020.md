# 固定快讯动态正文模板与关闭硬编码（2026-10-20）

## 入口

设置 → **栏目默认注释** → 页面下方的 **动态正文模板**。

五个栏目各自有：

- **使用内置硬编码正文** 开关（默认开启）；
- **团队正文模板** 文本框；
- 可用变量提示。

关闭开关并保存后，该栏目不再使用 `app/briefs` 里的硬编码正文，改用团队模板。若模板仍为空，关闭开关时会自动填入一个可编辑的起步模板，避免出现“必须填写团队正文模板”的阻断。

## 工作方式

1. 原有适配器照常取数、计算、制图和归档；
2. 如果使用内置文案，保持当前行为；
3. 如果关闭内置文案，用团队模板替换 `dynamic_body`；
4. 模板只允许命名变量，不允许 Python 表达式、属性访问或任意代码；
5. 模板渲染后仍进入 Skill AI 润色和数字守卫；
6. AI 未配置、额度耗尽或失败时，回退到该团队模板，任务仍成功；
7. 模板改动只影响后续新生成稿件，不回写已有版本。

`{date}` `{quote_date}` `{quote_time}` `{dr007}` `{dr001}` `{builtin_body}`

### 原油ETF

`{date}` `{previous_date}` `{uso_wan_barrels}` `{bno_wan_barrels}` `{previous_uso_wan_barrels}` `{previous_bno_wan_barrels}` `{uso_change_wan_barrels}` `{bno_change_wan_barrels}` `{builtin_body}`

`{builtin_body}` 可用来在旧正文前后包裹内容；如果目标只是改写“前一条有效交易日/条有效交易日”，建议直接写完整模板：

```text
{date}，沪深两市成交额为{amount_wan_yi}万亿元，较前一交易日{change_yi}亿元，变动{change_pct}%；连续{streak}个交易日{side}20日均线（{ma20_wan_yi}万亿元）。成交活跃度较前日{activity}。
```

## 数据与安全

- 模板保存在团队设置 `brief_templates`，按团队隔离。
- 保存时校验变量名；未知变量、空白模板（关闭内置时）返回 422。
- 模板不改变数字、图表、图片、固定注释或发布流程。
- 计算值仍来自原适配器；模板不能补造原文没有的数字。
- 数字守卫在 Skill 文案阶段继续生效；如果模板与规则稿数字不一致，AI 结果会被拒绝并回退模板/规则稿。

## 边界

- 目前只覆盖五个固定快讯栏目；美股晴雨表/美股结构仍使用内置文案。
- 模板是团队级设置，不按账号隔离。
- 改动不会自动重做已有稿件；需要新生成/重绘才会生效。
- 模板不能修复数据源缺失；来源日期缺口仍按数据事实处理。
