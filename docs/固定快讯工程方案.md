# PLUS工作台与固定快讯工程方案

本文件记录已确定的需求及本分支实现边界。基线为main提交`02bd6ec478525f27bdc766002ca45730b8449caa`。本分支不自行合并main、不操作生产服务器。

## 产品与排期

- 首页为四入口工作台：日报选稿、固定快讯、Plus新鲜事、Plus注解辅助。后两项首期是说明占位页。
- 现有日报功能移至`/daily/`，现有团队、账号、API、采集插件及日报导出保留。
- 固定快讯位于`/briefs/`，包含成交额、换手率、估值、流动性、原油ETF五项。
- 每项交付标题、完整正文、所需图片；原油ETF免配图。固定解释由程序追加，不由AI改写。
- 人工修改产生新版本；确认时绑定具体文字和图片。重跑不覆盖人工稿或原正式版本。系统不对外自动发布。
- 最新排期：北京时间周一至周五08:00开始，完成一项即停止该项，最晚10:00截止。无中国假期日历。周一取周五，其余取前一个工作日；流动性取当天。美国假期无新数据则等待/跳过，不拿旧日期冒充目标日期。
- 流动性从09:20等央行公告与DR数据；未就绪时在09:25、09:40、09:55补查。其余项目08:00起，失败可在08:30、09:00、09:20、09:40、09:55补查。
- 口径差异先进入测试核对，不阻挡测试部署；不存在的数据不能编造。正式确认前须勾选已阅读来源说明。

## 工程结构

```text
现有Caddy / HTTPS
  └─ 现有FastAPI：门户、日报、固定快讯API
        ├─ PostgreSQL：独立brief_*表，复用账号和团队
        └─ 受鉴权保护的文件下载

独立brief-worker容器
  ├─ PostgreSQL持久化队列 / 30秒空闲休眠
  ├─ 免费数据抓取 → 日期与单位校验 → 计算 → 代码制图
  ├─ 规则稿先保存 → 可选DeepSeek表达 → 版本入库
  └─ 持久化文件卷：来源、全历史、图片和快照
```

新代码集中于`jin10-server/app/briefs/`，不复用日报Material、Board、Issue业务表。后台取数和Matplotlib绘图都在独立子进程执行，HTTP仅入队，返回202。

新增`brief_configs`、`brief_issues`、`brief_versions`、`brief_jobs`、`brief_audits`五张表。各队列任务由唯一active_key去重；同一团队、日期、栏目不会同时跑两遍。PostgreSQL advisory lock限制单个生产worker，队列行锁认领。7分钟租约恢复中断任务，单次子进程最多6分钟，生产到10:00终止。

生成版本和编辑版本均不可覆盖。保存带base_version，冲突返回409。编辑新稿后，原已确认版本继续可取用，直到确认新版本。viewer只能读取和导出已确认文字及图片；editor/admin可编辑、运行和确认；只有admin可开启排期。

## 接口与页面

页面：`/`、`/daily/`、`/briefs/`、`/fresh/`、`/annotations/`、`/login/`。新页面复用现有`plus.token`和`/api/auth/*`，不新增账号体系。原`/app.js`、`/style.css`、`/guide.html`及插件下载URL保留。

固定快讯接口统一位于`/api/briefs`：

| 接口 | 职责 |
|---|---|
| GET categories / PUT config | 栏目、权限、排期与开关 |
| GET issues?date= / GET issues/{id} | 当天看板、成品、来源和任务状态 |
| POST jobs / GET jobs/{id} | produce、refresh、render、ai任务及状态 |
| GET issues/{id}/versions | 生成与编辑版本历史 |
| POST issues/{id}/revisions | 带版本号保存人工编辑 |
| POST issues/{id}/confirm或unconfirm | 确认及撤回，写审计记录 |
| GET issues/{id}/files/{number}/{name} | 带团队和文件哈希检查的图片读取 |
| GET issues/{id}/export | 导出完整正文或图文ZIP |

网页支持生产日期选择、五栏目状态、标题/动态正文修改、固定说明预览、版本切换、来源核对、确认、复制标题/完整正文、下载图片/图文包。API key不传给浏览器。原始数据与异常原因在核验信息中保留，不进入日常正文。

## 五项数据与模板

1. 成交额：金十沪深明细，排除北交所；完整有效记录计算含当日MA20，校验目标日期后绘图。
2. 换手率：正常访问乐咕页面，观察其正常返回的数据，不生成签名或绕过认证；完整历史计算9日均线后截十年窗口；复用用户1118×1407底版，仅改曲线和动态日期。
3. 估值：中证收盘价、雪球基金市值加权PE候选源、中债10年期国债收益率；全历史保存并更新前日。巴菲特指数用东方财富全A上市公司总市值/上年度GDP，保留原站历史，明确来源过渡不等同于原站数值。巴菲特图与原模板ERP图合并为一张纵图。
4. 流动性：中国货币网DR行情/历史，央行官网公开市场业务公告。区分盘中行情、历史日加权值和当日7天期逆回购利率；使用用户原始蓝色Logo，输出2160宽白底长图。
5. 原油ETF：USCF发行方公开持仓与净值。期货按确认的1000桶规格；USO掉期测试估算按当前最邻近合约参考价折算，明确待对账。连续采集后，对前一工作日同口径快照计算增减；首次没有前日持仓则不写单日增减。

所有成功快照复用，produce不重复请求外部来源。refresh显式取新数据，ai只补跑模型；render不取新数据。正文固定段集中在delivery.py，不依赖模型。历史、原始响应、日期、单位和来源差异随版本可追溯。

## 初版边界和验收

- 源差异允许部署测试、由编辑核对后确认；未完整复现口径的地方持续在warnings中展示。
- 成交额、换手率、估值、流动性的“重新制图”均从已保存快照重新绘图，不额外取数；原油ETF无需图片。
- DeepSeek当前采用事实安全的完整表达候选选择，不允许修改数字和增加未验证判断；未配置真实Key时只记录not_configured。
- 快讯文件独立保存，不适用日报7天清理。首版不自动删除快讯版本及其图片，后续可增加明确保留策略。
- GDP分母已配置2025全年版本；缺少新年度GDP时暂停估值，不自动沿用旧分母，年度更新见数据源文档。
- 本机已执行HTTP实取、计算、绘图和API测试；Docker/Linux及生产服务器验收交由接手机器执行，不能把本机结果写成已部署。

验收覆盖：原日报回归、门户路由、团队隔离、只读权限、并发入队、版本冲突、确认绑定图片哈希、固定说明去重、工作日/周一映射、10点截止、来源日期不符、同日缓存及失败不覆盖旧正式稿。
