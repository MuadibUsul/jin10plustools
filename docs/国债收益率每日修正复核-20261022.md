# 十年期国债收益率每日修正复核（2026-10-22）

## 规则

每日估值稿件生产时，中债国债收益率不再只在历史缺少当天数据才更新，而是固定重新抓取最近两个已完成交易日：

- 最新交易日：作为当天收益率输入；
- 上一交易日：重新核对此前已保存的收盘值。

判定规则：

- 数值变化（包括精度不同但数值不同）记为修正，立即替换历史值；
- 仅展示格式不同、数值相同不记为修正；
- 历史缺失的日期补入，并单独记录为新增；
- 修正后重算全部历史 ERP，回写滚动历史、`erp-history.json` 和数据库 `valuation_observations`。

复核报告写入本次运行的 `erp/raw/bond-update/revision-check.json`，并进入来源归档和过程详情。发生修正时，稿件警告会明确列出日期和旧值→新值。

## 失败隔离

国债复核现在排在 PE、沪深300收盘抓取之前。即使后续 PE 源暂时缺少前一交易日、导致稿件生成失败，已经抓取到的国债数据仍会写回持久历史；源快照和复核报告留在本次运行目录，供下次重试使用。

手动生成估值稿件会强制刷新，不复用同日已完成快照，确保编辑点击“生成稿件”时重新执行国债复核。

## 验证

- 新增测试覆盖：上一交易日数值修正、仅格式变化不算修正、缺失日期补入、即使历史已有最新日仍重新抓取最近两天。
- 完整后端回归：`307 passed, 4 skipped`。
- 生产验证（2026-10-22）：复核 `2026-10-20`（上一交易日）与 `2026-10-21`（最新交易日）；`2026-10-20` 为 `1.6354` 未修正，`2026-10-21` 为 `1.6412` 补入历史。随后估值稿件仍因雪球 PE 源缺少 `2026-10-20` 而未生成，但国债历史已正常推进，重试时不会重复缺失。
