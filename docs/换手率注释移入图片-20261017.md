# A股换手率注释移入图片（2026-10-17）

## 需求

- A股换手率图下方增加与市场估值指标一致的注释块（图中虚线含义、指标用法）。
- 图片长度不要明显超过当前换手率图；注释移入图片后，正文不再包含“本期注释”式的文字说明。

## 实现

- 注释位置：`version_out` 对 `valuation` 与 `turnover` 统一返回 `notes_placement: image`；前端编辑区自动显示“注释（保存后显示在图片底部）”。
- 正文：`complete_body` 对换手率不再追加固定注释块，并从旧稿件里剥离历史的“--------\n注：”块（换算为北京时间等日期格式后再剥离），因此正文、动态正文与“复制完整正文”都只含当日事实。旧版本仍按原样保存在数据库中，不修改历史记录。
- 图片：交付时（`delivered_image`）为换手率传入 `fixed_notes`，与估值共用 `compose_image` 的底部注释排版（深色底、浅灰字、原水印右下角）；换手率交付策略版本改为 `4-turnover-notes-1`，既有交付缓存会按新策略重新生成，无需重新制图。
- 尺寸：模板图 1118×1407，注释 201 字在 20px 字号下 5 行；交付图为 1118×1703（+296px，相对当前带水印交付图 1514px 增加约 12.5%），192,789 字节，低于 266,000 字节上限；保持原宽高比与清晰度，未缩放。
- 忠实性：注释文字仍是各团队可编辑的默认注释/本期注释（默认值与设置页一致），不写死在渲染代码里。
