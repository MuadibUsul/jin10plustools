# 数据库导出（2026-10-17）

## 需求

- 设置左侧新增“数据库”入口，专门导出已存入数据库的结构化数据，可按任意时间范围选择。
- 默认时间段：最近三个月、年内、近一年、全部已存；另支持自定义开始/结束日期（北京时间自然日）。
- 导出格式支持主流格式：Excel（.xlsx）、CSV（UTF-8 BOM，Excel 直接打开）、JSON。
- 以后所有数据都结构化存在数据库中并可按时间导出；新增数据表只需在注册表中登记即可获得导出入口。

## 页面

- 设置页改为左侧分区导航：团队设置 / 数据库。数据库入口对所有已登录成员可见（2026-10-19 起；此前仅管理员）。
- 数据库面板：数据集选择、时间范围按钮（最近三个月 / 年内 / 近一年 / 全部已存 / 自定义）、格式选择、预览条数、导出下载；数据集说明与可导出的列在折叠区列出。
- 导出下载前先统计行数：显示“当前范围共 N 行”，超过上限时提示缩小范围；下载完成后显示范围与行数。
- 自定义范围校验开始日期不晚于结束日期。

## 数据集（团队隔离）

| 数据集 | 筛选字段 | 范围 |
| --- | --- | --- |
| 素材库 | 采集时间 | 含已删除素材（删除时间列）、正文、栏目评分、PLUS解读、编辑修改 |
| 素材图片 | 入库时间 | 登记信息与校验值（图片文件本体在存储卷） |
| 日报记录 | 日报日期 | 页数、导出路径、制作人 |
| 选稿板 | 选稿日期 | 已选素材、首页精选、栏目排序 |
| 采集异常 | 上报时间 | 异常类型与说明（原始 HTML 不导出） |
| 快讯期次 | 生产日期 | 版本与确认状态 |
| 快讯版本 | 生产日期 | 全部历史版本，含完整稿件数据（JSON） |
| 快讯任务 | 生产日期 | 队列状态、尝试次数与错误 |
| 快讯来源快照 | 数据日 | 归档文件清单与哈希（文件本体在数据卷） |
| 快讯审核记录 | 操作时间 | 确认、撤回与保存操作 |
| 使用者反馈 | 提交时间 | 标题、内容、提交人姓名与账号、示意图元数据（2026-10-17 新增，见《使用者反馈-20261017》） |

- 账号与密码哈希、加密后的 AI Key、原始网页 HTML、来源快照二进制不提供导出。
- 时间过滤按北京时间自然日换算（存储为 UTC）；日期型字段直接按日期比较。
- 单次上限 50,000 行，避免一次性导出拖垮服务；时间范围可由前端预设或自定义。
- 用户 ID 统一解析为成员姓名；JSON 类字段在 CSV/Excel 中为 JSON 文本，在 JSON 导出中保持结构化。

## 实现

- `app/services/data_export.py`：数据集注册表（字段白名单、日期字段、联表与排序）、行读取、CSV/XLSX/JSON 生成；新增表在这里登记一条即可，接口与页面无需改动。
- `app/api/export.py`：`GET /api/export/datasets`、`GET /api/export/{dataset}/count`、`GET /api/export/{dataset}`；仅要求登录（2026-10-19 起所有账号可用），数据仍严格按团队隔离，返回带中文文件名的下载（RFC 5987）。
- `app/web/settings.html` / `settings.js` / `workspace.css`：左侧导航与数据库面板。
- 新增依赖 `openpyxl`（pyproject）。
