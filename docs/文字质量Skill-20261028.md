# 文字质量检查 Skill

2026-10-28：新增团队可管理的 `news.editorial-quality` 文字 Skill，位于「Skill 库 → 内容质量 → 文字质量检查」。管理员可修改、停用或恢复内置规范；团队设置保留修订历史。

此规范借鉴 [de-armor](https://github.com/ninetyhe-90/de-armor) 的任务导向检查思路，由本项目独立编写，没有复制对方文件或脚本。当前应用于 Plus新鲜事和 Plus注解辅助。起草时将团队规范加入模型指令；生成后执行只读的基础检查，提示空泛措辞以及新鲜事备注遗漏待核查边界。检查结果随分析报告或注解草稿保存，编辑可在预览中看到。

基础检查不改写稿件、不调用额外模型、不声称核实事实，也不替代现有的原文证据校验、外部来源搜索和人工审核。停用后不再注入规范或执行基础检查。固定快讯的数字、图表和既有 Skill 生产规则不受影响。
