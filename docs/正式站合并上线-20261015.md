# 正式站合并上线（2026-10-15）

用户要求直接统一上线，取消独立测试地址，不迁入测试站数据、不增加回滚流程。此记录取代旧测试站验收文档中“尚未切换正式站”的状态说明。

## 当前入口

- `https://plus.tlines.tech/`：工作台。
- `/daily/`：原正式站日报选稿。
- `/briefs/`：固定快讯。
- `/fresh/`、`/annotations/`：预留入口，仍为占位功能。
- `/test`、`/test/` 及其子页面：不再提供服务，无兼容跳转。

## 部署状态

- 正式 Compose 项目仍为 `/home/deploy/plus`，保留原 `.env`、JWT、数据库及存储卷。
- API 与固定快讯 worker 统一使用 `plus-api:unified-20261015`；环境变量 `PLUS_RELEASE_IMAGE` 指定镜像。
- 使用 `deploy/Dockerfile.release` 复用已验证的运行环境，覆盖为未经 `/test` 改写的完整本地应用、数据库迁移和日报模板。
- 数据库从 `0007` 增量升级到 `0010`，没有恢复测试数据库快照。
- Caddy 的 PLUS 域名统一反代 `plus-api:8000`，删除 `/test` 专用路由；其他域名配置不变。
- `plus-next` 的 API、worker、数据库容器已停止；没有删除其历史文件或数据卷。
- 自动排期没有额外开启，测试站稿件没有迁入正式库。估值图及图片交付规则未修改。

## 实际验收

通过 `deploy/check_unified.py` 在正式容器中请求正式 HTTPS 域名：

- 首页、日报、固定快讯及两个预留入口均为 200，页面没有测试路径。
- `/test/`、`/test/briefs/` 为 404。
- 原账号令牌认证、素材池、共享选稿板、增量同步、空批次推送、图片存在性查询及快讯接口均正常。
- 原有日报 PPTX/PDF、素材图片下载正常。
- 使用正式库现有素材在临时目录实际调用日报渲染与 LibreOffice 转换，生成 7 页 PPTX 和 PDF，页数一致、PDF 含可提取文字，生成警告为空；未保存额外测试日报记录。
- 浏览器确认正式首页展示四个正确的新入口。

API 重启时保留原有的自动过期清理逻辑，日志显示按既定保留期清理 2 条素材、4 张无引用过期图片；43 份历史日报保留。

复查命令：

```sh
docker cp deploy/check_unified.py plus-api:/tmp/check_unified.py
docker exec plus-api python /tmp/check_unified.py https://plus.tlines.tech
```
