# 直播目录、卡片选择与单路播放（2026年10月16日）

## 最终行为

- 点击电脑鼠标进入类别卡片；物理滚轮向下/向上切换，点击类别后用同样方式选择频道。触屏和键盘另保留前后按钮。
- 卡片采用四类统一的软质3D卡通插画，文字由DOM渲染。卡片只显示名称和简单操作提示，不显示免登录、YouTube验证、来源类型或可用状态标签；这是用户最后明确要求。
- 浏览卡片不创建播放器。播放时同一浏览器同源页面通过Web Locks持有独占锁；先暂停并卸载旧video、销毁HLS实例或移除iframe，再释放锁。并发和延迟回调通过序号及AbortController取消。
- 跨标签页选播通过localStorage所有权信号协调；生成按钮提交请求前广播停止，页面检测到运行任务时也关闭直播；后台状态每8秒复核。页面隐藏/离开会停止，避免后台继续播放。
- 北京时间8:00（含）到23:00（不含）开放；服务端拒绝时段外播放请求，客户端按服务器时间设截止计时，到点停止。当前日期快讯任务等待/执行期间服务端也拒绝播放。
- 屏幕内提供返回与全屏，返回时保留原有生成文字流。电脑不改变五张卡片尺寸。
- 修正真实浏览器中3D父层挡住点击的问题：机身外层不接收命中，屏幕和鼠标显式接收；卡片/播放期间固定透视姿态。
