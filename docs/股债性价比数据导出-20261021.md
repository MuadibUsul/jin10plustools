# 股债性价比原始数据导出

设置 → 数据库新增数据集“股债性价比原始数据”，按交易日期筛选，支持 CSV、Excel 和 JSON。

导出列依次为：日期、沪深300收盘价、PE-TTM市值加权、中国十年期国债收益率（不需加百分号）、沪深300风险溢价指数。Excel 的后四列为可计算的数值。国债收益率使用百分数数值（如 2 代表 2%），ERP 使用小数（如 0.08 代表 8%），计算沿用 `1 / PE - 国债收益率 / 100`。

## 数据保存

- 新表 `valuation_observations` 按团队、交易日期唯一，所有已登录成员只能导出本团队的数据。
- 迁移 `0013` 从各团队最近一份通过哈希及输入校验的 ERP 完整历史快照回填；没有快照的团队保持空数据，不导入公共样例。
- 后续有效估值任务归档时更新结构化历史，既有原始来源快照继续保留。

## 验证

导出、迁移回填、来源归档及 runner 相关测试共 `16 passed`。已验证五列表头、日期范围、团队隔离、CSV/JSON/XLSX 数值以及从 `0012` 升级后的历史回填。
