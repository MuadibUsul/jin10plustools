安装采集插件（Chrome）
  1. 下载插件压缩包，解压到一个固定文件夹
  2. Chrome 打开 chrome://extensions，打开右上角「开发者模式」
  3. 点「加载已解压的扩展程序」，选择解压后的文件夹
  4. 点插件图标 →「登录团队」，用本网站的账号登录

更新插件：下载新压缩包覆盖原文件夹，在扩展页点刷新图标。
