chat2api

ChatGPT 网页端登录凭证池，供 Plus新鲜事与 Plus注解的 AI 调用。可直接粘贴 /api/auth/session 的整段 JSON、Cookie 行，或一行一个 AccessToken/RefreshToken；系统会自动提取 accessToken 或 refreshToken（加密的 sessionToken 不能用于刷新，会被忽略），凭证只保存在节点服务器上。

如何获取 Token

在已登录 chatgpt.com 的浏览器新标签打开 chatgpt.com/api/auth/session，全选复制整段 JSON 粘贴到下方即可。也可以在 chatgpt.com 的开发者工具 Console 运行下面这行，直接复制 accessToken：

fetch('/api/auth/session',{credentials:'include'}).then(r=>r.json()).then(j=>{const t=j.accessToken||j.sessionToken;if(!t)throw new Error('未登录或未找到 accessToken');return navigator.clipboard.writeText(t).then(()=>console.log('已复制 AccessToken，长度',t.length))})

如果看到 __Secure-next-auth.session-token.0 与 .1：那是同一个会话 Cookie 因超长被拆成两段，不是两个 Token，也不能用于 chat2api 刷新；直接使用上面的 accessToken 即可，不需要复制 Cookie。
