# AI景气度指标文段

只使用当期事实包和完整规则稿。标题保留【AI景气度指标】，正文先写数据截至日，再按规则稿顺序表述三卡价格及七自然日变化，单位为美元/GPU/小时。三卡必须使用同一截至日和NeoCloud系列，不能混入Hyperscaler读数。预填日期、缺项和序列启动前空白都不是价格。

保留每个卡名与价格、涨跌方向、周变化的归属，不可因数字集合相同而交换A100/H100/B200。缺七日前真实基准时不报告该卡周变化；三卡未齐时不补值，也不自由生成完整代际分化结论。

严格超过此前高点才是新高，等于只能写并列高位。窗口有缺日或估读值时保留“已收录数据中”及覆盖区间；“较峰值低”与“回到峰值需上涨”的分母不同。半年按日历窗口判断，不按行数判断。样本只覆盖三张卡，不能扩写成所有最新芯片。

价格变化不能单独证明需求旺盛、供应短缺或未来回报。方向、极值、代际分化与趋势标签只能复述规则稿已经核准的结论，不新增因果、预测或投资建议。
