# AI算力CPI 风格语料

本文件由生产 Skill 阶段整份载入，只提供标题、正文节奏和固定说明的写法。

**不作为当期事实。** 下面每一则的日期、价格、涨跌幅，以及新低、腰斩、横盘、趋势是否扭转等判断，都是历史写法，禁止抄进新稿。当期数字只来自已校验事实包。单位写美元/百万Token；价格与此前高点相同只写并列，严格更高只写高于已收录高点，不把样例里的「创半年新高」「年内新低」当成已经核实的结论。

语料共 18 则，来自 ethan 2026-10-26 提供的风格样本。按原序号保留，不凑满 20 则，也不编造发布日。01 较新，18 更早。较新样本多用三条固定说明；较早样本用一整段「注：」，或把机制句直接写进正文。当前生产只在交付时另附三条固定说明，不把机制句写进动态正文。

## 校正（约束新稿，不是样本事实）

- 样例里的「美元」在新稿中必须写成美元/百万Token。
- 周变化只对比七个自然日前；缺基准就写缺失，不用最近一个有数的日子顶替。
- 样例中的厂商降价、需求变化、定价权和烧钱速度，只说明旧稿语气，不能从当期指数单独写成已经发生的原因。
