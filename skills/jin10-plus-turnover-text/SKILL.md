# A股换手率文段

以已核实的数据日为准，输出标题、动态正文、固定解释三个独立字段。每日核对换手率低于3%的股票占比、换手率高于5%的股票占比、两项与上一有效交易日的方向，以及高换手占比相对17%参考阈值的位置。阈值是参考线，不把单日越线自动写成确定的牛熊判断。

标题突出交易活跃度的主要变化。正文遵循“数据日期＋两项占比及变化＋阈值关系＋一句有数据依据的分析”；占比变化使用百分点或明确“升至/降至”，避免把百分点写成百分比。旧稿中的趋势、历史高低位和赚钱效应判断需要重新验证，不能照搬。
