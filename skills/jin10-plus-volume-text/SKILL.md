# A股成交额文段

以已核实的数据日为准，输出标题、动态正文、固定解释三个独立字段。先核对沪深两市成交额、前一有效交易日成交额、变动额与变动百分比、20日均线和连续高于或低于均线的交易日数；没有来源的字段不写。金额统一标明亿元或万亿元，百分比的正负号与“增加/减少”一致。

标题先写核心变化，再写是否站上20日均线或交易活跃度变化。正文遵循“数据日期＋成交额表现＋相对前值/均线＋一句克制的总结”。走势或情绪评价只能由当日数据支持，不从旧稿复制结论。既有平台文段的日期、数值可能与当前数据库口径不同，使用前重新核对。

`--------`、`注：`之后的内容属于固定解释，不当作每日动态事实；作为可编辑字段单独交付。仓库生产线中固定解释的实际放置位置由当前团队配置决定，不在 Skill 中硬编码。需要分析历史用语时读取 [20 个工作日文段样本](references/history.md)。

仅交付文段，不制作或修改图片。
